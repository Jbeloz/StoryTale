# StoryTale RVC voice environment — dependency lock
#
# This records the Python environment that GENERATED the narration in
# assets/audio/narration/. It is a PC-side development tool only: it never
# runs in the Flutter app, on the web, or on a phone. The app plays the
# finished .wav files, and the planned mobile path is offline ONNX through
# sherpa-onnx, not this environment.
#
# Written on 2026-08-13, before the 6.2 GB venv was deleted to reclaim disk.
#
# WHAT IT IS FOR
#   tool/sync_voice_audio.py turns .tools/voice-work/*.mp3 plus the .pth
#   models in models/voices/raw/ into fingerprinted chapter audio.
#   You need this environment again only to (a) generate new narration, or
#   (b) export .pth models to ONNX for Phase 10.
#
# HOW TO REBUILD
#   The venv was created with uv (not pip); it has no pip inside it.
#
#     uv venv --python 3.10 .tools/rvc-venv
#     uv pip install --python .tools/rvc-venv/Scripts/python.exe `
#         --index-strategy unsafe-best-match `
#         --extra-index-url https://download.pytorch.org/whl/cu118 `
#         -r tool/rvc-requirements.txt
#
# THE TRAP
#   torch and torchaudio below are +cu118 CUDA builds. They do NOT exist on
#   the default PyPI index. Without the --extra-index-url above the install
#   fails, or silently resolves to a CPU-only build that does not match.
#   Original interpreter: Python 3.10.20 (cpython-3.10-windows-x86_64, via uv).
#
# Source audio is NOT in git. It is backed up at:
#   Desktop/IT Elect 4/storytale-voice-source-backup/

# Hero Face Prompt Pack

Attach the current neutral face overlay first and the empty compatible head
template second. Keep the background flat `#00FF00` so it can be removed
locally.

## Shared prompt

Create only the floating eyebrows, eyes, tiny nose, mouth, and simple cheek
accents for the same bright young male protagonist. Preserve the neutral reference's grayscale chibi
style, identity, front-facing direction, feature scale, spacing, white sclera,
and white pupil highlights. The empty head is alignment-only and must not be
drawn. Do not add a head, skin, hair, body, clothing, shadows, text, or extra
marks.

## Expression changes

- **Neutral:** Upbeat eyebrows, open lively eyes with clear highlights, and a
  friendly small smile; avoid a tired, blank, or expressionless look.
- **Talking:** Keep neutral eyebrows and eyes; use one small open speaking mouth.
- **Happy:** Brighten the same eyes and add a cheerful open smile.
- **Sad:** Slope the eyebrows upward toward the center, keep both eyes in place,
  and use a small downward-curved mouth.
- **Angry:** Angle the eyebrows downward toward the center, narrow both eyes
  without moving them, and use a small clenched-teeth mouth.
- **Surprised:** Raise the eyebrows, widen both eyes without moving them, and use
  a small open O mouth.

Final parts are normalized back to the approved neutral eye and mouth anchors
before they are bundled with the app.

The cheek accents are stored once as `details/bright_cheeks.png` and reused by
all six Hero sets.

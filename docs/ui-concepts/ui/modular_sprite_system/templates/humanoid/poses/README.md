# Humanoid Poses

Pose files will store joint rotation and position values instead of pictures. Start with neutral, talking, pointing, reaction, walk-left, walk-right, and idle-breathing poses. The same pose can be reused by characters that share a compatible rig.

New named poses start from Neutral in Sprite Studio. Pose files also store
validated layer overrides and a compatible rig ID. See
[Sprite Studio plan](../../../../../../SPRITE_STUDIO_PLAN.md).

# Finished Characters

Create one folder per finished character appearance. It references the shared
immutable head and nine body parts instead of copying them. Store modular face
parts and sets, front hair, optional back hair, saved hair fits, skin tone, up
to nine locally cut clothing overlays, optional garment/accessory layers,
preview composites, and the appearance manifest. Joint positions stay in the
shared rig and pose JSON.

See [Character Sheet V1 Plan](../../../../CHARACTER_SHEET_PLAN.md)
for the canonical generation and local-cut flow.

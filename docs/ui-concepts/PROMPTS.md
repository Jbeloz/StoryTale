# UI Mockup Prompt Set

## Shared rules

- Use case: `ui-mockup`
- Asset type: polished mobile app screen
- Portrait phone canvas with realistic product UI, practical spacing, and readable text
- Brand name: `StoryTale`
- No account profile, cloud sync, Supabase, marketplace, generated motion media, logos, trademarks, or watermarks
- DeepL is the only translation service shown
- Story Mode uses 2D sprites and simple movement
- Keep the same information architecture in all three visual directions

## Shared seven screens

1. Library: header, search, recent EPUB cards, reading progress, favorites, and `Upload EPUB` action.
2. Import EPUB: local file picker area, `.epub only`, privacy note, validation state, and `Add to Library` action.
3. Book Details: cover, title, author, progress, `Continue Reading`, and chapter list with Story Mode availability.
4. Reader + Translation: chapter text, reader controls, English/Filipino toggle, DeepL label, and translate action.
5. Narration: current passage, narrator voice, character voice assignments, play/pause, speed, and progress.
6. Story Mode: story background, two character sprites, subtitle box, movement cue, playback controls, and chapter progress.
7. Moral: completed chapter, short moral card, reflection prompt, and `Next Chapter` / `Back to Book` actions.

## Type 1 - Cozy Storybook

Warm cream background, forest teal, terracotta, honey yellow, soft illustrated accents, rounded cards, gentle shadows, friendly serif headings, clean sans-serif body text, playful but uncluttered.

## Type 2 - Clean Academic

Bright white and pale blue background, navy text, calm cyan accent, simple grid, compact cards, minimal decoration, high contrast, highly accessible sans-serif typography, structured and practical.

## Type 3 - Immersive Adventure

Deep navy background, twilight purple, warm gold accents, luminous illustrated scene panels, layered cards, cinematic but readable, elegant serif headings, clear controls, strongest visual emphasis on chapter Story Mode.

# Starter Actor Details

Each starter actor has one small reusable detail overlay:

| Actor | Detail file | Purpose |
| --- | --- | --- |
| Default | `soft_cheeks.png` | subtle neutral cheek accents |
| Hero | `bright_cheeks.png` | lively protagonist cheek marks |
| Heroine | `soft_blush.png` | simple cute blush accents |
| Elder | `wrinkles.png` | reusable age lines |
| Adult | `adult_lines.png` | subtle mature under-eye lines |

Details are transparent 1254 x 1254 PNGs. They stay separate from eyes, nose,
and mouth so one file works with every expression set.

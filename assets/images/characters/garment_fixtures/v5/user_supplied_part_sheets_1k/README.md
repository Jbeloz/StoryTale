# User-supplied clothing part sheets — 1K

These are the three owner-supplied clothing review sheets saved from the
conversation:

- `torso_clothing_1k.png` — torso clothing sheet.
- `arms_clothing_1k.png` — upper-arm clothing and lower-arm/hand sheet.
- `legs_clothing_1k.png` — upper-leg clothing and filled-shoe lower-leg sheet.

Every review copy is exactly `1024 x 1024` PNG. The original pasted files are
preserved in `source/`. The torso source arrived as `1022 x 1022`; its review
copy reaches 1K by adding a one-pixel replicated edge border, without resizing
or blurring the supplied artwork. The arms and legs copies are byte-exact.

These are review references only. They are not registered in Flutter, are not
runtime garments, and have not been sent to an image provider.
